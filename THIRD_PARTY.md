## doomgeneric

- [Source](https://github.com/ozkl/doomgeneric)
- Pinned commit: `dcb7a8dbc7a16ce3dda29382ac9aae9d77d21284`
- License: GPL v2; individual source headers generally permit v2 or later.

The checkout in `vendor/doomgeneric/` is unmodified and excluded from Git. The build replaces the X11 backend with the native platform adapter, selects 320×200 output, and renames `I_Quit` / `I_Error` in `i_system.c` for host lifecycle handling. A generated copy of `i_sound.c` removes the unused SDL_mixer include; sound is enabled in the dispatcher and configuration code.

A generated copy of `st_stuff.c` includes `Sources/StatusFace.inc` to export the current Doomguy face from the WAD, independently of the in-game HUD. No standalone sprites or textures extracted from the WAD are stored in the repository. Documentation screenshots show the running game and contain game imagery; that imagery is not covered by the source-code GPL.

The upstream license is included in the local app bundle.
